# Machine-Learning-Based-Early-Prediction-of-Lifestyle-Diseases
Aagahi
Lifestyle-Based Health Risk Awareness Tool

Aagahi is a web-based health awareness tool that estimates a user's risk patterns for common lifestyle-related health conditions based on their lifestyle and health information.

Know what's ahead.

What Does It Do?

Users answer a short questionnaire about their:

Age, height & weight
Physical activity
Smoking
Diet
General health
Physical & mental health
Cholesterol
Healthcare access
Education & income

Aagahi then provides estimated risk levels for:

🩸 Diabetes
🩺 Hypertension
🧠 Stroke
❤️ Heart Disease

It also shows an age-based risk trajectory to visualize how estimated risk may change as the user gets older if their current inputs remain unchanged.

🤖 Machine Learning

The project uses Logistic Regression models trained on the BRFSS 2015 health indicators dataset.

The trained model weights are embedded directly into JavaScript, allowing predictions to run completely in the browser.

🚀 How to Run

No installation or backend is required.

Simply open:

aagahi.html

in a modern web browser.

⚠️ Disclaimer

Aagahi is an awareness and screening prototype, not a medical diagnostic tool.

The results are based on patterns learned from population-level data and should not be considered medical advice or a clinical diagnosis.
